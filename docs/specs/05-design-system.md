# Frontend Design Reference

This is a reference to the current frontend presentation, not a normative product requirement. The Vue application includes an operational shell and feature pages under `frontend/src`.

The changelog records historical visual decisions: Inter as the global font, shared visual tokens, responsive shell/navigation, and improved text contrast. These notes describe recorded work; they do not replace inspection of current styles or establish accessibility conformance.

Before changing the interface, inspect the relevant Vue components, shared styles, and existing product flows. Keep operational labels concise and prioritize clarity for point-of-sale tasks. No visual or accessibility tests were run as part of the documentation update.
