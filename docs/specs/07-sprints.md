# Historical Delivery Notes

This page preserves the former delivery sequence as historical project context. It is not a current roadmap, release record, or proof that the listed work is complete.

The historical sequence covered schema and triggers, authentication, catalog, customers, cash, tables and commands, orders, payments and ingredient deduction, dashboard, and the Vue application. Subsequent notes mention in-memory frontend token handling, visual updates, the `payment_method` field, and documentation reorganization.

The project is now documented as SimplyCore. The earlier SimplyFood implementation remains visible in code identifiers and legacy SQL filenames. Current scope and decision status live in the [product specification](01-produto.md) and [decision register](../decisions/README.md). Dated historical notes remain in the [changelog](../CHANGELOG.md).
