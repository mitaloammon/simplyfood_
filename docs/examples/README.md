# Fictional Error Log Examples

The files in this directory are fictional training examples. They are not logs from a real SimplyCore installation and must not be treated as evidence about a running environment.

- `laravel-error.log` illustrates Laravel/Monolog output.
- `php-fpm-error.log` illustrates PHP-FPM output.

When reviewing a real incident, protect credentials and personal data. Record the timestamp, severity, error identifier, application frame, and verified environment context. Do not infer that a database, container, or service is reachable based only on a log excerpt.
