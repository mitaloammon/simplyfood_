# SimplyCore Specification Entry Point

SimplyCore is the intended modular, multi-tenant SaaS ERP platform for small and medium-sized businesses. The repository currently implements a FOOD_SERVICE operational application; the broader platform and RETAIL workflows are not complete.

Approved architectural decisions describe constraints, not completed implementation.
